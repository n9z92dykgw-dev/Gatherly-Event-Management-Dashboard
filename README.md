GATHERLY EVENT MANAGEMENT DASHBOARD

Gatherly is a modern event management dashboard for organizing events, managing guests, tracking attendance, monitoring tasks, and overseeing event operations in one workspace.

FEATURES
- View upcoming events and event statistics
- Add, edit, search, and filter events
- Manage guest counts and attendance
- Review today's agenda and open tasks
- Responsive dashboard layout for desktop and mobile

RUN LOCALLY
1. Open index.html in a web browser.
2. No build tools or dependencies are required.

PROJECT FILES
- index.html: Dashboard structure and content
- styles.css: Layout and visual styling
- script.js: Dashboard interactions and event data
- .gitignore: Files excluded from Git tracking
